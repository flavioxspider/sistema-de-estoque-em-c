# Sistema de Controle de Estoque em C

Sistema de controle de estoque desenvolvido em linguagem C como parte do meu portfólio de projetos em Ciência da Computação.

O projeto foi desenvolvido com foco na prática de lógica de programação, estruturas de dados, modularização, manipulação de arquivos e validação de dados.

## Funcionalidades

- Cadastro de produtos
- Listagem de produtos
- Busca de produtos por ID
- Alteração de produtos
- Exclusão de produtos
- Registro de entrada de estoque
- Registro de saída de estoque
- Verificação de estoque insuficiente
- Identificação de produtos com estoque baixo
- Geração automática de IDs
- Salvamento dos dados em arquivo
- Carregamento automático dos dados ao iniciar o sistema
- Validação dos dados de entrada

## Tecnologias utilizadas

- Linguagem C
- Dev-C++
- Git
- GitHub
